## Status

This release is a Korean working-paper release of `Jaemin Cosmology`.

The manuscript proposes a speculative formal framework for modeling consciousness, intuition, cognitive efficiency, AGI efficiency gaps, and subjective time through the hypothesis of a higher-dimensional information interface.

It is not an empirically confirmed theory of physics, neuroscience, consciousness, cognitive science, or AI.

## Scope

This release prepares the Korean Typst manuscript and public repository materials for archival release.

It includes:

- Korean Typst manuscript source
- Reproducible Typst build commands
- Bilingual README files
- Scope and non-goals documents
- English and Korean abstracts
- English and Korean one-page summaries
- English and Korean FAQ documents
- AI assistance disclosure
- Citation, license, and Zenodo metadata scaffolding
- Reference audit document with PR 14 bibliography metadata verification status
- GitHub Actions workflow for building the Korean PDF

## Known Limitations

- The framework is not empirically validated.
- Core parameters such as `c`, `η`, `λ`, and `α` require operationalization.
- Candidate predictions require comparison against standard neuroscience, cognitive science, psychology, physics, and AI models.
- Bibliographic metadata completed the PR 14 consistency pass; all 19 entries are verified in `docs/reference-audit.md`.
- The current release is primarily Korean.

## Non-Goals

This release does not claim that the manuscript is an empirically confirmed theory.

It does not claim that the brain literally accesses extra physical dimensions.

It does not claim to replace standard physics, neuroscience, cognitive science, psychology, or AI research.

It does not claim that AGI is impossible in principle.

It does not treat intuition as supernatural.

## Build Instructions

Required tools:

- Typst CLI 0.14.2 or newer
- Korean font such as `Noto Sans CJK KR`, `NanumGothic`, or `Malgun Gothic`

Recommended command:

```bash
make build
```

Direct Typst command:

```bash
typst compile --root . paper/ko/main-ko.typ paper/ko/main-ko.pdf
```
