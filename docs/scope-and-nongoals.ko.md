# 범위와 비목표

이 문서는 `Jaemin Cosmology / 재민 우주론` 원고의 공개 범위와 비목표를 명확히 하기 위한 설명 문서다.

## 현재 지위

이 원고는 한국어 working paper이며, 의식, 직관, 지능, AGI 효율성 격차, 주관적 시간 경험을 하나의 형식 구조로 정리하려는 사변적 연구 프로그램이다.

이 문서는 검증된 물리 이론, 신경과학 이론, 또는 경험적으로 확증된 과학 이론을 주장하지 않는다.

## 다루는 범위

이 문서는 다음을 하나의 수학적 가설 공간으로 정리하려는 시도다.

- 의식 경험을 저차원 투영으로 모델링하는 방식
- 잠재의식 또는 비의식적 처리를 고차원 표현으로 해석하는 방식
- 직관을 압축된 신호 또는 latent structure 접근으로 표현하는 방식
- 인간 지능과 AGI의 차이를 원리적 불가능성이 아니라 계산 효율성 격차로 해석하는 방식
- 주관적 시간 경험을 내부 시간율 모형으로 다루는 방식

## 주장하지 않는 것

이 문서는 표준 물리학 또는 표준 신경과학을 대체한다고 주장하지 않는다.

이 문서는 뇌가 실제 물리적 추가 차원에 직접 접근한다고 확정적으로 주장하지 않는다.

이 문서는 직관을 초자연적 능력으로 설명하지 않는다.

이 문서는 AGI가 원리적으로 불가능하다고 주장하지 않는다.

## 연구적 가치

이 문서의 가치는 검증 가능한 하위 가설과 후보 예측을 도출하는 데 있다.

향후 이 프레임워크가 경험 과학으로 발전하려면 표준 신경과학, 인지과학, 물리학, AI 모형과 구별되는 측정 가능한 예측을 제시해야 한다.
