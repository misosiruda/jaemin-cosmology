# 외부 리뷰 요청서

## 상태

이 요청서는 Jaemin Cosmology working-paper 원고와 English Draft v0.2.0에 대한 외부 리뷰 요청입니다.

- DOI-bearing release: 한국어 working-paper release `v0.1.0-ko`
- DOI: https://doi.org/10.5281/zenodo.20506269
- 영어 draft 상태: 리뷰용 초안, 별도 release 아님
- 참고문헌 상태: bibliography citation placement와 reference metadata verification은 아직 pending

영어 draft는 비판적 검토를 위한 review draft로 읽어야 합니다. 이는 권위 있는 공개본이 아니며 별도 DOI도 없습니다.

## 프로젝트 요약

이 원고는 뇌를 상위차원 정보 제약 구조와 저차원 의식 경험 사이의 인터페이스로 모델링할 수 있는지 탐구하는 사변적 formal framework입니다. 의식 경험, 잠재의식 또는 비의식 표현, 직관, 인지 효율성, AGI 효율성 격차, 주관적 또는 내부 시간을 하나의 수학적 어휘 안에서 정리합니다.

이 프레임워크는 경험적으로 검증된 과학 이론으로 제시되지 않습니다. 뇌가 문자 그대로 추가 물리 차원에 접근한다고 주장하지 않으며, 표준 물리학, 신경과학, 인지과학, 심리학, AI 연구를 대체한다고 주장하지 않습니다.

## 리뷰 요청

동의나 지지가 아니라 취약점 탐지를 중심으로 비판적 리뷰를 부탁드립니다. 저자는 이 프레임워크가 참이라고 보증해 달라고 요청하는 것이 아닙니다.

유용한 리뷰 영역은 다음과 같습니다.

- 개념적 명료성
- 수학적 일관성
- 용어와 표기 명료성
- 주장 강도 조절
- 반증가능성과 후보 예측
- 일반 latent-variable model, predictive-processing model, representation-learning model, information-theoretic model, cognitive-efficiency model과의 관계
- AGI 효율성 격차 framing
- 주관적 시간 모델링
- 식별가능성 문제
- 누락되었거나 약한 문헌 근거

## 중요한 주의사항

- 후보 예측은 확정된 예측이 아닙니다.
- `η_proxy`와 관련 수량은 후보 operational proxy이며 최종 측정값이 아닙니다.
- AGI 논의는 효율성 격차 lens이며 AGI 불가능론이 아닙니다.
- 주관적 시간 모델링은 노화에 따라 물리적 시간이 빨라진다는 주장이 아닙니다.
- 기대수명과 문명 가속 논의는 사변적 heuristic extension으로 읽어야 합니다.
- 회전 메커니즘은 optional special case이며 핵심 가정이 아닙니다.
- Bibliography citation placement와 reference metadata verification은 아직 pending입니다.
