# Review Distribution Checklist

Use this checklist before sending English Draft v0.2.0 to 3-5 technical sanity-check reviewers. Do not use this process for broad public promotion.

## Status Context

- DOI-bearing release: Korean working-paper release `v0.1.0-ko`
- DOI URL: https://doi.org/10.5281/zenodo.20506269
- English Draft v0.2.0 is not separately released and has no separate DOI
- English Draft v0.2.0 is a review draft, not the authoritative published version
- Review purpose: technical sanity checking, not endorsement
- Bibliography metadata has been audited; reviewers may still suggest missing, stronger, or more appropriate literature

## Framing Check

- [ ] The materials describe the work as a speculative formal framework, not a verified theory.
- [ ] The materials do not imply empirical confirmation.
- [ ] The materials do not imply literal access to extra physical dimensions.
- [ ] The materials do not claim to replace physics, neuroscience, cognitive science, psychology, or AI research.
- [ ] The materials do not frame intuition as supernatural.
- [ ] The AGI section is not framed as AGI impossibility.
- [ ] The AGI section is not framed as an AGI guarantee.
- [ ] Subjective time acceleration is not framed as having one proven cause.
- [ ] Life expectancy and civilizational acceleration are framed as speculative heuristic extensions.
- [ ] Rotational mechanisms are framed as optional special cases.

## Reviewer Selection

- [ ] Select 3-5 first-pass technical sanity-check reviewers.
- [ ] Include at least two distinct reviewer categories if possible.
- [ ] Prioritize reviewers from AI / ML / AGI efficiency.
- [ ] Prioritize reviewers from cognitive science / neuroscience.
- [ ] Prioritize reviewers from mathematics / information theory / formal modeling.
- [ ] Consider a reviewer from philosophy of science / philosophy of mind.
- [ ] Consider a reviewer from subjective time / memory / aging.
- [ ] Record candidates in [reviewer-shortlist-template.md](reviewer-shortlist-template.md).

## Packet Preparation

- [ ] Build the English Draft v0.2.0 PDF.
- [ ] Confirm the Korean DOI-bearing release link resolves: https://doi.org/10.5281/zenodo.20506269
- [ ] Confirm the English draft is labeled as not separately released and without a separate DOI.
- [ ] Include the review packet listed in [review-packet-manifest.md](review-packet-manifest.md).
- [ ] Choose whether to send a Google Form, response template, or both.
- [ ] Fill in `[repo link]`, `[link or attachment]`, `[link]`, and `[review window]` placeholders in the email template.

## Outreach Control

- [ ] Send only to selected reviewers; do not perform broad public distribution.
- [ ] State explicitly that the request is not an endorsement request.
- [ ] Track outreach in [review-tracking-template.md](review-tracking-template.md).
- [ ] Record permission before quoting, naming, or acknowledging reviewers.
- [ ] Keep reviewer feedback separate from bibliography metadata unless a citation change is independently verified.

## After Feedback Arrives

- [ ] Group feedback by theme.
- [ ] Separate factual corrections from interpretive suggestions.
- [ ] Verify any proposed bibliography metadata before changing `references/references.bib`.
- [ ] Preserve cautious framing when revising.
- [ ] Do not create a release, tag, DOI, ORCID, or affiliation entry as part of feedback intake.
