# Review Checklist

이 checklist는 원고가 의도한 범위와 review-draft status를 유지하는지 점검하기 위한 문서입니다.

## 상태와 release framing

- [ ] 한국어 `v0.1.0-ko`가 DOI-bearing release로 취급된다.
- [ ] DOI가 https://doi.org/10.5281/zenodo.20506269 로 명시된다.
- [ ] English Draft v0.2.0이 별도 DOI release로 취급되지 않는다.
- [ ] English Draft v0.2.0이 review draft로 명확히 제시된다.
- [ ] Bibliography verification은 pending으로 남아 있다.

## 주장 강도

- [ ] 주장 강도가 조심스럽다.
- [ ] 경험적 확증이 주장되지 않는다.
- [ ] verified theory처럼 읽히는 표현이 없다.
- [ ] Candidate prediction이 confirmed prediction처럼 제시되지 않는다.
- [ ] Modeling implication이 empirical law처럼 제시되지 않는다.
- [ ] Measurement proxy가 final measurement처럼 제시되지 않는다.

## 범위 경계

- [ ] Literal extra-dimensional access가 주장되지 않는다.
- [ ] 물리학, 신경과학, 인지과학, 심리학, AI 연구를 대체한다고 주장하지 않는다.
- [ ] AGI impossibility claim이 없다.
- [ ] AGI guarantee claim이 없다.
- [ ] Physical causality violation이 암시되지 않는다.
- [ ] 직관이 초자연적 능력으로 취급되지 않는다.
- [ ] 주관적 시간 가속이 검증된 단일 원인 현상처럼 제시되지 않는다.
- [ ] 기대수명과 문명 가속 논의가 speculative heuristic extension으로 제시된다.
- [ ] 회전 메커니즘이 core assumption이 아니라 optional special case로 제시된다.

## 수학과 operational clarity

- [ ] `P`, `Q_c`, `G`, `Q_F`가 일관되게 정의된다.
- [ ] `c`, `η`, `α`, `λ`가 operationalization이 필요한 formal parameter로 취급된다.
- [ ] `Q_F`가 외부 주입이 아니라 alignment/coupling component로 설명된다.
- [ ] `η_proxy`가 candidate operational proxy로 취급된다.
- [ ] `D_felt(a,T)`가 modeled felt duration으로 명확하다.
- [ ] Physical time과 internal/subjective time이 명확히 분리된다.

## Baseline model과 testability

- [ ] Ordinary latent-variable model이 인정된다.
- [ ] Predictive-processing model이 인정된다.
- [ ] Representation-learning model이 인정된다.
- [ ] Information-theoretic model이 인정된다.
- [ ] Cognitive-efficiency model이 인정된다.
- [ ] Higher-dimensional interpretation 전에 baseline comparison이 요구된다.
- [ ] Candidate prediction이 측정 가능한 변수를 제시하거나 operationalization 필요성을 명시한다.
- [ ] 프레임워크를 약화하거나 반증할 수 있는 관측이 식별된다.

## 문헌과 참고문헌

- [ ] 누락 문헌은 metadata verification과 분리해 표시된다.
- [ ] 약하거나 근거가 부족한 주장은 citation review 대상으로 표시된다.
- [ ] 검증되지 않은 DOI, ISBN, arXiv, publisher, journal, page, URL metadata가 추가되지 않는다.
- [ ] Bibliography citation placement는 pending follow-up으로 남아 있다.
